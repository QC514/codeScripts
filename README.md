# codeScripts

个人自用的自动化脚本合集，主要用于日常签到、会员任务和活动辅助。仓库包含 JavaScript 与 Python 脚本，并持续按实际使用情况维护。

## 仓库内容

- JavaScript 脚本：63 个
- Python 脚本：13 个
- 多数脚本已接入统一的运行日志与通知适配
- 每个脚本所需的环境变量、依赖和定时规则可能不同，请优先阅读对应文件头部的说明

## 使用方式

### 克隆仓库

```bash
git clone https://github.com/QC514/codeScripts.git
cd codeScripts
```

### 本地运行

JavaScript 脚本需要安装 Node.js：

```bash
node "脚本名称.js"
```

Python 脚本需要安装 Python 3：

```bash
python "脚本名称.py"
```

如脚本依赖第三方模块，请根据终端报错或脚本头部说明安装相应依赖。

### 青龙面板订阅

```bash
ql repo https://github.com/QC514/codeScripts.git "" "" "" ""
```

订阅完成后，请按各脚本头部说明配置环境变量和定时任务。建议将不同任务的执行时间错开，避免并发运行造成接口拥堵或触发频率限制。

## VX_GO 环境变量

| 变量名 | 格式 | 示例 |
|--------|------|------|
| `VX_GO` | `地址#openid[#auth]`，换行或 `&` 分隔 | `172.17.0.4:8000#XXXXXXXXXX#myauth` |
| `auth` | 全局默认 auth（可选，账号未带 auth 时回退使用） | `myauth` |

配置时请注意：

- 地址不要带 `http://` 前缀。
- 不要使用容器名（如 `vx-go`），请使用 IP 地址。
- 单个账号内分隔符支持 `#` 和 `@`，格式为 `地址#openid#auth` 或 `地址#openid`。
- 账号未带 auth 时，从全局 `auth` 环境变量读取。
- 多个账号支持换行分隔，也支持用 `&` 连接写在同一行。
- 所有发往 VX_GO 服务的请求会自动携带 `Authorization` 请求头。
- 脚本不会同时执行，青龙定时任务需要手动错开 cron。

## 通知配置

部分脚本支持企业微信机器人通知，可使用以下任一环境变量提供机器人 Key：

- `QYWX_KEY`
- `QYWX`
- `WEWORK_KEY`

通知属于可选功能；脚本是否支持以及具体行为，请以对应脚本代码和注释为准。
